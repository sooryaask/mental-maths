Wrong-answer sound
==================

Put an audio file called  wrong.mp3  in this folder and it plays every time
someone gets a question wrong. Without it, the site plays a built-in
"sad trombone" instead.

Tips
- Keep it short (1-3 seconds) so it doesn't overlap the next question.
- Keep it small (under ~200 KB) so it loads quickly on phones.
- The file name must be exactly  wrong.mp3  (lower case).
- Upload the whole folder to Netlify again after adding it.
- Only use audio you're allowed to use: the site is public, and clips from
  TV, films or YouTube can be copyright-protected.
- On iPhone, no sound plays while the phone's silent switch is on.
